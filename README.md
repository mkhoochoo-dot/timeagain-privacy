# TimeAgain 개인정보처리방침

안드로이드 앱 **TimeAgain** (`com.ecofamia.timeagain`) 의 개인정보처리방침입니다.

구글 플레이 콘솔이 공개 URL 을 요구해서 이 저장소만 공개로 둡니다.
앱 소스는 별도의 비공개 저장소에 있습니다.

- 공개 주소: https://mkhoochoo-dot.github.io/timeagain-privacy/
- 원본: FeedBrake 저장소의 `docs/privacy.html`

내용을 고칠 때는 앱 저장소의 `docs/privacy.html` 을 먼저 고치고 여기로 복사합니다.
두 곳이 달라지면 어느 쪽이 진짜인지 알 수 없게 됩니다.
